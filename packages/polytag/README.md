# polytag

Headless CRUD for tag-based collections, on top of [zodal](https://github.com/i2mint/zodal) and [zodal-groups](https://github.com/i2mint/zodal-groups). Pre-release scaffold: no usable API yet. See the [repository](https://github.com/i2mint/polytag) for the plan.

Entry points: `polytag` (tag-aware), `polytag/formats`, `polytag/backends`, `polytag/views` (tag-agnostic).
